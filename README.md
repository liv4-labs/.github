# .github

Questo repository non contiene codice. Fornisce i **file di default** che GitHub applica a
tutti i repo di `liv4-labs` che non ne hanno uno proprio:

- `.github/ISSUE_TEMPLATE/task.yml` — il modulo con cui si apre una issue
- `.github/PULL_REQUEST_TEMPLATE.md` — la descrizione precompilata delle pull request

Un repo che ha bisogno di una versione diversa se la mette in casa propria: la sua vince.

Dev'essere pubblico perché GitHub applichi i default agli altri repo, anche privati. Per questo
qui non va niente di interno: `CONTRIBUTING`, `SECURITY` e simili restano nei singoli repo.

Il processo che questi file presuppongono vive nel Project
[LIV4 delivery](https://github.com/orgs/liv4-labs/projects/7).
